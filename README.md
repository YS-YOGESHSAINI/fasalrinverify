# fasalrinverify
An extension to auto verify the fasal rin loan applications.
. first download the zip of this extension
. open the path "C:\Users\{user}\AppData\Local\Microsoft\Edge\User Data\Default\Extensions"
. extract the file over here

Install the Extension in Microsoft Edge
Once you have saved both files in your folder, follow these steps to load it into Edge:

   .Open Microsoft Edge and type edge://extensions/ in the address bar, then press Enter.
   .Look at the bottom-left corner of the extensions page and toggle on Developer mode.
   .Click the Load unpacked button that appears near the top-left.
   .Select the folder where you saved your manifest.json and content.js files.

   now open https://fasalrin.gov.in/loan-application-list
   start the extension and enter the number of entries to be verified.
